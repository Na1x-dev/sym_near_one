# Na1x.exe — Cyberpunk Portfolio

Одностраничный сайт-визитка junior fullstack developer в неоновой эстетике киберпанка. Сделан с нуля как статический HTML/CSS/JS без сборки и зависимостей.

## Запуск локально

Откройте `index.html` в браузере.

## Деплой на GitHub Pages

1. Откройте **Settings → Pages**.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Выберите ветку `cyberpunk-portfolio` и папку `/ (root)`, затем нажмите **Save**.
4. Дождитесь публикации сайта в Pages.

## Перед публикацией

- Замените имя/ник `Na1x`, если нужно.
- Укажите актуальный стек технологий.
- Замените три демо-карточки на реальные проекты и добавьте ссылки на репозитории/демо.
- Замените `hello@example.com` на свой email.

Страница адаптивна, не требует Node.js или npm и включает стили и скрипт прямо в `index.html`.
