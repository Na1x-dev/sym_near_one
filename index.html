TechMatcher

Full-stack web application designed to make smartphone selection easier through a searchable product catalog and side-by-side device comparison. Users can explore detailed smartphone specifications, compare multiple models, manage their shopping carts, and create personal accounts. The application also features an automated data collection system that keeps the product catalog updated. The frontend is built with React and Redux Toolkit, while the backend uses Django REST Framework to provide REST API endpoints, authentication, and user management. Background tasks are handled by Celery and Redis.

Ai Content Helper

Full-stack SaaS platform designed to simplify content creation with artificial intelligence. The application allows users to generate platform-specific content for Telegram, VC.ru, and X (Twitter), customize writing styles, and manage their daily generation limits through a subscription-based system.
